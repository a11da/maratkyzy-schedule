# Маратқызы Д. — Моё расписание

[Открыть приложение](https://a11da.github.io/maratkyzy-schedule/)

24 занятия в недельном шаблоне, перенесённые с предоставленной таблицы. На таблице нет дат: повторение с 12 октября по 31 декабря 2026 условное. Праздники, переносы и сессия не учтены.

В четверг на 10:00–10:50 в таблице указаны два семинара. По указанию пользователя сохранены оба с пометкой «Уточнить».

## Установка на iPhone

Откройте сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить». Если доступно «Открывать как веб-приложение», включите его. Первый раз запустите с интернетом для загрузки офлайн-кэша.

## Данные

Заметки и посещаемость хранятся локально под отдельными ключами `maratkyzy-pwa-*`. Приложение использует собственный кэш `maratkyzy-autumn2026-*` и обслуживает только свой адрес. Репозиторий и публикация отдельные от ИС-24-2.

GitHub Pages публикует корень ветки `main`. При обновлении файлов увеличивайте версию кэша в `sw.js`.
